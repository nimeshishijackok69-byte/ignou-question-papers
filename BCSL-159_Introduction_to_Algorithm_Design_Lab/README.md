# BCSL-159: Introduction to Algorithm Design Lab

## Examination & Course Structure Note

**BCSL-159** is a 2-credit practical laboratory course under the IGNOU BCA / BCA_NEW program (Semester 5), serving as the companion lab for **BCS-042 (Introduction to Algorithm Design)**.

### Why Are There No Centralized Written TEE Papers?
Unlike theory courses (which have nationwide written Term-End Examinations with centrally archived papers), IGNOU conducts practical examinations differently:
1. **Term-End Practical Examination (TEPE):**
   - Conducted directly at the student's allotted Regional Centre / Study Centre computer lab.
   - Students are assigned interactive programming tasks (in C language) to implement, compile, and execute on the spot, followed by a viva voce with an external/internal examiner.
2. **Lab Assignments & Continuous Assessment:**
   - Students complete exercises outlined in the official lab manual and assignment problems.
3. **Core Practical Topics Covered:**
   - Recursion & time complexity (Fibonacci, Tower of Hanoi)
   - Efficient numerical algorithms (Horner's rule for polynomials, matrix multiplication)
   - Divide-and-conquer algorithms (Merge sort, Quick sort, binary search)
   - Greedy algorithms (Fractional Knapsack problem, Huffman coding)
   - Dynamic programming & graph traversal algorithms (DFS, BFS, cycle detection)
