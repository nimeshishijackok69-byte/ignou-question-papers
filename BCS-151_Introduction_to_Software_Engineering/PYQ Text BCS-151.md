# June 2025

**BCS–051** | BACHELOR OF COMPUTER APPLICATIONS [BCA (REVISED)]
Term-End Examination | **June, 2025**
**BCS-051 : INTRODUCTION TO SOFTWARE ENGINEERING**
Time : 3 Hours | Maximum Marks : 100

**Note :** Question No. 1 is compulsory and carries 40 marks. Attempt any three questions from the rest.

### 1.
**(a)** Compare Waterfall model and Spiral model for software development. Explain the situation, in which the Spiral model for software development should be preferred over Waterfall model.
*(10 marks)*

**(b)** What is GANTT chart ? Compare the utility of GANTT and PERT charts. Draw GANTT chart for the development of "Online Railway Reservation System".
*(10 marks)*

**(c)** Discuss IEEE SRS format and use it to develop the SRS for "Online Railway Reservation System". Make necessary assumptions.
*(15 marks)*

**(d)** What are static objects ? Explain with the help of a suitable example.
*(5 marks)*

### 2.
**(a)** Briefly discuss the various notations used to draw usecase diagram. Draw a usecase diagram for "Online Railway Reservation System".
*(10 marks)*

**(b)** Compare Black Box Testing and White Box Testing. Give suitable example for each.
*(10 marks)*

### 3.
**(a)** Briefly discuss the various notations of DFD. Draw first two levels of DFDs for an "Online Examination System". Make necessary assumptions.
*(10 marks)*

**(b)** What is the need of project planning ? Discuss any four types of project plans.
*(10 marks)*

### 4.
**(a)** What is the need of software maintenance ? Explain different categories of software maintenance.
*(10 marks)*

**(b)** What is a test case ? Explain test case for functional testing with the help of an example.
*(10 marks)*

### 5.
Briefly discuss the following with suitable example for each : *(4×5=20)*
  (a) Acceptance testing
  (b) Alpha and Beta testing
  (c) Module testing
  (d) Integration testing
  (e) Software Quality Assurance activities

> ⚠ As printed: the paper says 4×5=20 but lists five items (a)–(e). Check the original PDF.

# December 2025

**BCS–051** | BACHELOR OF COMPUTER APPLICATIONS (BCA) (REVISED)
Term-End Examination | **December, 2025**
**BCS-051 : INTRODUCTION TO SOFTWARE ENGINEERING**
Time : 3 Hours | Maximum Marks : 100 | Weightage : 75%

**Note :** Question No. 1 is compulsory and carries 40 marks. Attempt any three questions from the rest.

### 1.
**(a)** Develop SRS for Online Assignment Submission and Evaluation System for a University. Use IEEE format for SRS. Make necessary assumptions.
*(20 marks)*

**(b)** What is an object ? Explain application logic object with an example. Also, explain specifications of static object.
*(10 marks)*

**(c)** What is structured analysis ? Explain.
*(5 marks)*

**(d)** Explain the principles of software testing.
*(5 marks)*

### 2.
**(a)** Explain Waterfall Model with the help of a suitable diagram. List advantages and disadvantages of this model.
*(10 marks)*

**(b)** Draw a sample Gantt chart for an online examination system. Make necessary assumptions.
*(10 marks)*

### 3.
**(a)** Explain System testing and Regression testing.
*(10 marks)*

**(b)** What is the need of software maintenance ? Briefly explain different types of software maintenance.
*(10 marks)*

### 4.
**(a)** What is Software Configuration Management (SCM) ? Explain SCM activities briefly.
*(10 marks)*

**(b)** What is a DFD ? What are the components of DFD ? Draw first two levels of DFDs for Online Assignment Submission and Evaluation System. Make necessary assumptions.
*(10 marks)*

### 5.
Write short notes on the following : *(4×5=20)*
  (a) Reverse Engineering
  (b) Capability Maturity Model (CMM)
  (c) Debugging
  (d) Use-case diagram
